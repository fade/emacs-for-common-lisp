#+TITLE: Remote & Tramp
#+AUTHOR: Brian O'Reilly

This configuration is optimized for working on remote clusters and servers via Tramp and Sly.

* Tramp Configuration
** Connection Properties
We use specialized connection properties to ensure stability on remote hosts:
- *Remote Shell*: Fixed to =/bin/sh= for known hosts (like =synthia=) to avoid issues with complex shells (zsh/fish) on the remote side.
- *Terminal Type*: Set to =dumb= to prevent control character interference.
- *VC Handled Backends*: Disabled for remote connections to significantly speed up file opening.

** Performance Tuning
To keep the UI responsive during remote work:
- Remote LSP features are aggressively throttled (no lenses, breadcrumbs, etc.).
- TCP timeouts are reduced to 0.5s for remote buffers to prevent long hangs on network issues.

* Provisioning Remote Hosts
We provide a standalone script, [[file:../provision-remote.sh][provision-remote.sh]], to stand up a development environment on a new host.

** What it does:
1. Sets up =~/.local/bin= and adds it to the PATH.
2. Installs =Node.js= via NVM (required for some language servers).
3. Installs =bash-language-server= and =python-lsp-server=.
4. Syncs SLY extensions (like =sly-quicklisp=, =sly-asdf=) from the local machine to the remote.
5. Sets up Roswell symlinks for ASDF discovery.
6. Creates a durable =start-slynk.sh= script to run Slynk inside a =tmux= session.

** Usage:
#+BEGIN_SRC bash
./provision-remote.sh <hostname>
#+END_SRC

* The Synthia Cluster
Special configurations exist for the NRC =synthia= cluster:
- *Default Lisp*: Configured via connection-local variables to use =ros= (Roswell).
- *Filename Translations*: Map remote paths back to local Emacs paths for seamless SLY interaction.

* Remote SLY Connections
To ensure reliability and prevent "leakage" of remote paths into local sessions, we use a manual connection workflow.

** Manual Connection Workflow
1. Establish an SSH tunnel in your terminal:
   #+BEGIN_SRC shell
   ssh -L 4005:localhost:4005 user@remote-host
   #+END_SRC
2. In Emacs, use *C-q s r* (=fade/sly-connect-remote=).
3. Provide the remote hostname (for TRAMP path translation) and the local port.

This command explicitly registers the TRAMP translator for that session, ensuring that commands like =sly-asdf-open-system= find files on the remote disk rather than looking locally.

** Local-First Philosophy
By default, SLY assumes connections are local to avoid the overhead and brittleness of automatic TRAMP path generation. Automatic translation is reserved for specific, known hosts like the *Synthia Cluster*.
