* TL;DR
This is a comprehensive, literate Emacs configuration centered around *Common Lisp* development, *Org-mode* productivity, and *Remote* system management. It uses =straight.el= for reproducible package management and =org-babel= to tangle the configuration from =config.org=.

** Quick Start
1. Clone this repo to =~/.emacs.d=.
2. Open Emacs; =straight.el= will bootstrap and install all packages.
3. Use =C-q s s= to start a local Common Lisp REPL.
4. For remote work, establish an SSH tunnel and use =C-q s r= to connect reliably.
5. Use =./provision-remote.sh <host>= to set up remote Slynk/LSP environments.

* Overview
This configuration is designed for high-performance Lisp development with a "Sly-first" philosophy. It balances the deep image-based introspection of *SLY* with the modern diagnostic and navigation capabilities of *LSP*.

** Key Pillars
- *Common Lisp Development*: Deep SLY integration with custom Tramp support and Roswell-awareness.
- *Literate Configuration*: All logic lives in [[file:config.org][config.org]], allowing for extensive documentation alongside the code.
- *Remote Workflow*: Specialized Tramp connection properties and provisioning scripts for cluster environments.
- *Modern UI*: Uses =Corfu= for completion, =Vertico/Consult= for narrowing, and custom =Deepsky= themes.
